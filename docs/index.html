Что это

WearCraft — десктопное приложение для процедурной генерации износа PBR-текстур. Загрузи PBR-сет (albedo, normal, roughness, ao, height, metalness, edge), сгенерируй N уникальных вариаций износа и экспортируй в игровые движки.

Встроенный 3D-вьюер показывает результат в реальном времени. Превью полностью совпадает с запечённым результатом — что видишь, то и получишь.

WearCraft v1.0.0

Procedural wear generator for PBR textures

Download for Windows itch.io GitHub

What is it

WearCraft is a desktop application for procedural wear generation on PBR texture sets. Load a PBR set (albedo, normal, roughness, ao, height, metalness, edge), generate N unique wear variations, and export to game engines.

The built-in 3D viewer shows the result in real time. The preview fully matches the baked result — what you see is what you get.

Features

Presets

Custom mask, procedural scratches, spots, rust

Masks

Own mask (single PNG) or library (folder-based, %APPDATA%)

Positioning

Move, rotate, scale each spot. Tiling control per variation

Parallel Generation

Rayon-powered. N unique variations, each with own seed

3D Viewer

Sphere, cube, cylinder, torus, or your own .obj / .gltf model

Engine Export

Unreal (ORM + DX normal), Unity (MetallicSmoothness, Built-in / URP)

i18n

Russian, English, 中文

PBR Presets

All parameters tuned per material type

PBR 纹理程序化磨损生成器

下载 Windows 版 itch.io GitHub

简介

WearCraft 是一款用于 PBR 纹理程序化磨损生成的桌面应用。加载 PBR 纹理集（albedo、normal、roughness、ao、height、metalness、edge），生成 N 个独特的磨损变体，并导出到游戏引擎。

内置 3D 查看器实时显示结果。预览与烘焙结果完全一致 — 所见即所得。

功能

预设

自定义遮罩、程序化刮痕、斑点、锈迹

遮罩

自有遮罩（单个 PNG）或库（%APPDATA% 文件夹）

定位

移动、旋转、缩放每个斑点。每个变体的平铺控制

并行生成

基于 rayon。N 个独特变体，每个有自己的种子

3D 查看器

球体、立方体、圆柱、圆环，或自定义 .obj / .gltf 模型

引擎导出

Unreal（ORM + DX 法线）、Unity（MetallicSmoothness，Built-in / URP）

多语言

俄语、英语、中文

PBR 预设

所有参数按材质类型调优
